# ☁ Nextcloud

> Self-hosted productivity platform — files, calendar, contacts, office

**Category:** productivity  
**Tags:** `files`, `calendar`, `office`, `collaboration`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :x: |
| **Group Admin** | :x: |
| **Access Group** | `users_nextcloud` |
| **Admin Group** | `admin_nextcloud` |

!!! info "Auth Notes"
    OIDC login via oidc_login app. Group mapping possible but not yet configured. Admin set manually in Nextcloud.
