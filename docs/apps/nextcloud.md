# ☁ Nextcloud

> Self-hosted productivity platform — files, calendar, contacts, office

**Category:** productivity  
**Tags:** `files`, `calendar`, `office`, `collaboration`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `forward-auth` |
| **SSO** | :x: No |
| **Group Access** | :white_check_mark: |
| **Group Admin** | :x: |
| **Access Group** | `users_nextcloud` |
| **Admin Group** | `admin_nextcloud` |

!!! info "Auth Notes"
    Access gated by forward-auth + group-gate; Nextcloud then shows its own login (admin account uses NEXTCLOUD_ADMIN_PASSWORD). No OIDC app is installed yet. Desktop/mobile sync clients and WebDAV cannot pass the forward-auth redirect.


## Environment Variables

| Variable | Description | Generation |
|----------|-------------|------------|
| `NEXTCLOUD_ADMIN_PASSWORD` | Nextcloud admin password | `random` |
