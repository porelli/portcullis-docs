# 📺 Jellyfin

> Free and open-source media server — movies, TV, music, live TV

**Category:** media  
**Tags:** `media`, `movies`, `tv`, `music`, `streaming`, `opensource`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :white_check_mark: |
| **Group Admin** | :white_check_mark: |
| **Access Group** | `users_jellyfin` |
| **Admin Group** | `admin_jellyfin` |

!!! info "Auth Notes"
    SSO-Auth plugin with group enforcement. Users must be in access_group to log in. Members of admin_group get Jellyfin admin. Configured automatically by setup sidecar.

## Settings

User-configurable options available in the Hub UI:

| Setting | Type | Description |
|---------|------|-------------|
| **Movies folder** | `path` | Host path to your movies library → `/data/movies` |
| **TV Shows folder** | `path` | Host path to your TV shows library → `/data/tv` |
| **Music folder** | `path` | Host path to your music library → `/data/music` |

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `JELLYFIN_ADMIN_PASSWORD` | Jellyfin admin password | `random` |
| `JELLYFIN_OIDC_SECRET` | Jellyfin OIDC client secret | `random` |
