# 🎬 Plex

> Media server for movies, TV, music with transcoding and client apps

**Category:** media  
**Tags:** `media`, `movies`, `tv`, `music`, `streaming`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `custom` |
| **SSO** | :x: No |
| **Group Access** | :x: |
| **Group Admin** | :x: |

!!! info "Auth Notes"
    Plex uses its own plex.tv account system. No SSO or group integration possible. Claim token required for initial setup.

## Settings

User-configurable options available in the Hub UI:

| Setting | Type | Description |
|---------|------|-------------|
| **Movies folder** | `path` | Host path to your movies library → `/data/movies` |
| **TV Shows folder** | `path` | Host path to your TV shows library → `/data/tv` |
| **Music folder** | `path` | Host path to your music library → `/data/music` |

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `PLEX_CLAIM` | Plex claim token (get from https://plex.tv/claim) | `none` |

## Access URLs

- **Plex**: `https://plex.{{DOMAIN}}`
