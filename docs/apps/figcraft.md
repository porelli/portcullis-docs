!!! info "Auth Notes"
    Early alpha upstream (https://getartcraft.com/apps): expect missing features and breaking changes between versions. FigCraft (https://github.com/storytold/figcraft, Apache-2.0 OR MIT) is a static site: the app runs in the visitor's browser and has no user system, no server-side code and no server-side storage. Open uses the browser's file picker, Save/Export download files; preferences live in the browser's storage for this hostname. Portcullis sign-in (forward-auth + group-gate) is the only login; every member of the access group gets the same app (there are no roles). At every start the figcraft-fetch init container downloads the release's figcraft-web-<version>.zip from GitHub, checks its SHA-256 against the pin before unpacking, and swaps the unpacked site into the figcraft-site volume by rename; on any error it exits non-zero and the web server doesn't start (an unchanged pin skips the download). The host needs outbound HTTPS to github.com. The web server (nginx-unprivileged, read-only, no directory listing) answers only Traefik and itself. Version: CRAFT_VERSION / CRAFT_SHA256 default to the pin in compose.yml (bumped with the template); set both together, from the release's SHA256SUMS.txt, to pin another release.

## Environment Variables

Per-app variables in the generated `.env`; `random` ones are generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `CRAFT_VERSION` | FigCraft release to serve (x.y.z, without the "v"). Empty = the version pinned in compose.yml. Set CRAFT_SHA256 with it.
 | `none` |
| `CRAFT_SHA256` | SHA-256 of figcraft-web-<CRAFT_VERSION>.zip (lowercase hex, from the release's SHA256SUMS.txt). Empty = the pin in compose.yml. A mismatch stops the start.
 | `none` |
