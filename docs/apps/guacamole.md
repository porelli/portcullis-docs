# 🖥 Apache Guacamole

> Clientless remote desktop gateway — RDP, SSH, VNC in the browser

**Category:** remote-access  
**Tags:** `rdp`, `ssh`, `vnc`, `remote-desktop`, `browser`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `header-auth` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :white_check_mark: |
| **Group Admin** | :x: |
| **Access Group** | `users_guacamole` |
| **Admin Group** | `admin_guacamole` |

!!! info "Auth Notes"
    Forward-auth + group-gate, then Guacamole's header extension trusts X-Forwarded-User from oauth2-proxy (accounts auto-created with no permissions). The extension has no proxy allowlist, so a Tomcat RewriteValve rejects (403) any request carrying X-Forwarded-User that does not come from Traefik (PORTCULLIS_TRAEFIK_IP). The built-in guacadmin account gets a random password (GUACAMOLE_ADMIN_PASSWORD) on first boot; set GUACAMOLE_ADMIN_USER before first enable to make that SSO user the administrator instead. Connection permissions are managed in the Guacamole UI. Changing either value after the database is initialized has no effect.


## Settings

User-configurable options available in the Hub UI:

| Setting | Type | Description |
|---------|------|-------------|
| **Administrator SSO username** | `text` | SSO username (as sent in X-Forwarded-User) that becomes the Guacamole administrator. Applied only on first database initialization. Leave empty to keep a local guacadmin account with a random password.
 |

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `GUACAMOLE_DB_PASSWORD` | Guacamole database password | `random` |
| `GUACAMOLE_ADMIN_PASSWORD` | Password for the built-in Guacamole administrator (replaces the default guacadmin/guacadmin) | `random` |
