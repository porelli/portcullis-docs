# 🖥 Apache Guacamole

> Clientless remote desktop gateway — RDP, SSH, VNC in the browser

**Category:** remote-access  
**Tags:** `rdp`, `ssh`, `vnc`, `remote-desktop`, `browser`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :x: |
| **Group Admin** | :x: |
| **Access Group** | `users_guacamole` |
| **Admin Group** | `admin_guacamole` |

!!! info "Auth Notes"
    OpenID Connect with Keycloak plus HTTP header auth fallback. No native group-based access control — connection permissions managed in Guacamole UI.
