# 🐦 NetBird

> Mesh VPN + zero-trust networking with TURN relay

**Category:** vpn  
**Tags:** `vpn`, `wireguard`, `mesh`, `zero-trust`

!!! warning "Conflicts with: headscale"

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :x: |
| **Group Admin** | :x: |
| **Access Group** | `users_netbird` |
| **Admin Group** | `admin_netbird` |

!!! info "Auth Notes"
    Dashboard uses OIDC. Management API validates JWT audience. No group-based access restriction — all OIDC users can access dashboard.

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `NETBIRD_OIDC_CLIENT_SECRET` | OIDC client secret for NetBird dashboard | `random` |
| `COTURN_EXTERNAL_IP` | Public IP for TURN relay (required for NAT traversal) | `none` |
| `COTURN_AUTH_SECRET` | Shared secret for TURN authentication | `random` |
