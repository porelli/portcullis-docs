# 📖 Wiki.js

> Modern wiki — mTLS if cert present, WebAuthn fallback

**Category:** productivity  
**Tags:** `wiki`, `docs`, `knowledge-base`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `forward-auth` |
| **SSO** | :x: No |
| **Group Access** | :white_check_mark: |
| **Group Admin** | :x: |
| **Access Group** | `users_wiki` |
| **Admin Group** | `admin_wiki` |
| **Subdomain** | `wiki` |

!!! info "Auth Notes"
    No SSO configured yet. Access gated by group-gate middleware. Wiki.js supports OIDC natively but needs manual setup after wizard.

## Routing

Traefik routers from `compose.yml`. The Hub replaces the TLS tier with the one derived from the app's [access policy](../operations/auth-policies.md#traefik-tls-tier).

| Router | Host | Paths | TLS tier | Forward-auth + group-gate |
|--------|------|-------|----------|---------------------------|
| `wiki` | `wiki.<domain>` | all | `authaware@file` | :white_check_mark: |
