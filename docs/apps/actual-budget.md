# 💰 Actual Budget

> Privacy-first local budgeting app with bank sync

**Category:** finance  
**Tags:** `budget`, `finance`, `money`, `tracking`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :x: |
| **Group Admin** | :x: |
| **Access Group** | `users_actual-budget` |
| **Admin Group** | `admin_actual-budget` |

!!! info "Auth Notes"
    OpenID login with auto-register. No native group/role support — all SSO users get equal access.
