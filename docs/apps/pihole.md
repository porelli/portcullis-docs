# 🚫 Pi-hole

> Network-wide ad blocking via DNS sinkhole

**Category:** networking  
**Tags:** `dns`, `adblock`, `privacy`, `filtering`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `forward-auth` |
| **SSO** | :x: No |
| **Group Access** | :white_check_mark: |
| **Group Admin** | :x: |
| **Access Group** | `users_pihole` |
| **Admin Group** | `admin_pihole` |
| **Subdomain** | `pihole` |

!!! info "Auth Notes"
    No SSO support. Has its own web password. Access gated by group-gate middleware.
