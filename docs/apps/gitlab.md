## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :x: |
| **Group Admin** | :x: |
| **Access Group** | `users_gitea` |
| **Admin Group** | `admin_gitea` |

!!! info "Auth Notes"
    Full OIDC with Keycloak. User provisioning and role mapping possible via OIDC claims but not yet configured.

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `GITLAB_ROOT_PASSWORD` | GitLab root password | `random` |
| `GITLAB_OIDC_SECRET` | GitLab OIDC client secret | `random` |
