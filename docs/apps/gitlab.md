# 🦊 GitLab

> Complete DevOps platform — Git, CI/CD, container registry, issue tracking

**Category:** devops  
**Tags:** `git`, `ci-cd`, `devops`, `registry`, `issues`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :x: |
| **Group Admin** | :x: |
| **Access Group** | `users_gitlab` |
| **Admin Group** | `admin_gitlab` |

!!! info "Auth Notes"
    Full OIDC with Keycloak. No forward-auth in front of GitLab so git-over-HTTPS, the API and CI runners work with personal access tokens. Any realm user can sign in (accounts auto-created); group restriction and role mapping via OIDC claims not yet configured.

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `GITLAB_ROOT_PASSWORD` | GitLab root password | `random` |
| `GITLAB_OIDC_SECRET` | GitLab OIDC client secret | `random` |
