# 🤖 LiteLLM

> Unified LLM proxy — OpenAI-compatible API for 100+ models with auth and rate limits

**Category:** ai  
**Tags:** `llm`, `ai`, `openai`, `proxy`, `api`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `native-oidc` |
| **SSO** | :white_check_mark: Yes |
| **Group Access** | :x: |
| **Group Admin** | :x: |
| **Access Group** | `users_litellm` |
| **Admin Group** | `admin_litellm` |

!!! info "Auth Notes"
    OIDC login for the admin UI. API access uses master key, not SSO. No group-based restriction on UI access.

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `LITELLM_MASTER_KEY` | LiteLLM admin API key | `random` |
| `LITELLM_OIDC_SECRET` | LiteLLM OIDC client secret | `random` |

## Keycloak Clients

**LiteLLM** (`litellm`)

## Access URLs

- **LiteLLM Proxy**: `https://llm.{{DOMAIN}}`
