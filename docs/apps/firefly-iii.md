# 💸 Firefly III

> Self-hosted personal finance manager with double-entry bookkeeping

**Category:** finance  
**Tags:** `finance`, `accounting`, `budget`, `bookkeeping`

## Authentication

| Property | Value |
|----------|-------|
| **Method** | `header-auth` |
| **SSO** | :warning: Partial |
| **Group Access** | :white_check_mark: |
| **Group Admin** | :x: |
| **Access Group** | `users_firefly` |
| **Admin Group** | `admin_firefly` |

!!! info "Auth Notes"
    Uses remote_user_guard with X-Forwarded-User header from oauth2-proxy. Auto-creates user on first login. No group-based admin support.

## Environment Variables

Auto-generated by the Hub on first enable:

| Variable | Description | Generation |
|----------|-------------|------------|
| `FIREFLY_APP_KEY` | Firefly III encryption key (32 chars) | `random` |
| `FIREFLY_DB_PASSWORD` | Firefly III database password | `random` |

## Access URLs

- **Firefly III**: `https://finance.{{DOMAIN}}`
